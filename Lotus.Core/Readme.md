Модуль Core для Frontend приложений платформы Lotus

Базовая TypeScript-библиотека для frontend-приложений платформы Lotus.  
Содержит общие типы, утилиты, хелперы и доменные модули (API, маршруты, валидация, цвета и др.), которые переиспользуются между приложениями.

Пакет: `lotus-core` · версия `4.0.0`

## Возможности

- Общие типы и интерфейсы предметной области (`Result`, сущности, уведомления об изменениях)
- Хелперы для строк, массивов, дат, GUID, браузера и объектов
- Конвертеры и форматтеры значений (даты, числа, boolean, enum, размер файлов)
- HTTP API-слой, фильтрация/сортировка/пагинация запросов и ответов
- Маршрутизация, команды действий, валидация, локализация (RU/EN)
- Работа с цветами, палитрами и токенами; 2D/3D математика и canvas-утилиты

## Модули верхнего уровня

### `constants`
Набор символьных и строковых констант (в т.ч. `CharConstants`). Упрощает единообразную работу со спецсимволами без «магических» литералов в коде.

### `converters`
Преобразование значений между строковым/сырым представлением и типизированными данными. Поддерживает даты (`DateTimeConverter`), числа, boolean и enum.

### `environment`
Доступ к окружению приложения (development/production и опции). Позволяет централизованно читать флаги окружения и особенности runtime.

### `formatters`
Форматирование значений для отображения пользователю. Даты, числа и размеры в байтах с учётом локали и принятых в UI представлений.

### `graphics`
Утилиты для работы с HTML Canvas (`CanvasHelper`). Упрощают типичные операции рисования и измерения на canvas.

### `helpers`
Статические хелперы общего назначения: строки, массивы, объекты, даты, GUID, пути, cookie, браузер, устройство, enum, функции, изображения и др. Основной «инструментальный» слой библиотеки для повседневных задач.

### `localization`
Локализация ядра платформы: диспетчер языков, словари RU/EN и события смены языка. Даёт единый способ получать локализованные строки и реагировать на смену локали.

### `math`
Математические утилиты: `XMath`, 2D/3D-векторы и геометрия, шум и генераторы случайных значений. Используется для расчётов, графики и процедурной генерации.

### `resources`
Работа с ресурсами приложения: файловый сервис и модели файлов, а также типы/хранилище изображений. Описывает контракты для загрузки и использования медиа-ресурсов.

### `types`
Базовые типы и интерфейсы домена: `IResult`, сущности, ключи/GUID, геометрия (`IPoint`, `IRect`, `ISize`), `INotifyPropertyChanged`, редактируемость, хранилище и утилитарные type-helpers. Фундамент типизации для остальных модулей.

### `utils`
Низкоуровневые утилиты: проверки утверждений (`Assert`), таймер/`sleep`, именование объектов. Помогают валидировать данные в runtime и упрощать асинхронные сценарии.

## Доменные модули (`modules`)

### `actionCommand`
Паттерн команд действий: инкапсуляция операции вместе с метаданными UI (тип, навигация, разделитель). Связывает бизнес-действие с элементом интерфейса и сервисом выполнения команд.

### `api`
HTTP-клиентский слой (`ApiService`) с конфигурацией запросов, заголовками и типами контента. Упрощает вызовы backend API и обработку сетевых ошибок.

### `color`
Полноценная работа с цветом: парсинг CSS/hex/rgb/hsl, манипуляции, палитры, семантические цвета, токены и варианты оттенков. Подходит для тем оформления и дизайн-системы.

### `filter`
Описание функций фильтрации данных (`equals`, `contains`, `between` и др.) и их группировка по типам полей. Задаёт единый словарь операторов для UI-фильтров и запросов к API.

### `humanizer`
Человекочитаемое представление данных: ФИО в разных форматах и вспомогательное форматирование строк. Удобно для отображения пользователей и текстов в UI.

### `objectInfo`
Метаданные свойств объектов: дескрипторы, типы, сортировка, группировка, редактирование и визуальные настройки. Используется для динамических форм, таблиц и инспекторов объектов.

### `option`
Модель опций выбора (`value` / `label`) и хелперы для работы с ними. Упрощает построение select/autocomplete и преобразование списков в опции UI.

### `reactiveObject`
Базовый класс с подпиской на изменение свойств (`INotifyPropertyChanged`). Даёт лёгкую реактивность без привязки к конкретному UI-фреймворку.

### `refreshProxy`
Простой контракт/базовый класс для обновления прокси-объектов. Позволяет единообразно инициировать перезагрузку или refresh связанного состояния.

### `requestAndResponse`
Модели и хелперы запросов/ответов: фильтры, сортировка, пагинация, page-info. Стандартизирует обмен данными со списками и табличными API.

### `route`
Описание маршрутов приложения с флагами авторизации и правами доступа; есть типизированный вариант (`TypedRoute`). Упрощает декларацию навигации и построение путей с параметрами.

### `validation`
Результаты и правила валидации: уровни сообщений, билдер правил, базовый валидатор. Собирает ошибки/предупреждения по полям и удобно интегрируется с формами.

## Импорт

```ts
// весь пакет
import { Assert, ApiService, Color } from 'lotus-core';

// точечные подпакеты
import { StringHelper } from 'lotus-core/helpers';
import { LocalizationCore } from 'lotus-core/localization';
import { Route } from 'lotus-core/modules/route';
```
